# Шаблон ответа в чат

Скрипт печатает ответ сам; модель пересылает его без изменений.

```
Распределение пачки ФУЛ готово.

Обработано ФУЛ: {всего}
• Новых строк для Cloud: {новые} (с логистом — {с_логистом}, без логиста — {без_логиста})
• Повторных отправок: {повторы} (заказ уже в Cloud — {в_cloud}, дубль внутри пачки — {дубли})
• Возможных пропусков: {пропуски}
• Требует внимания: {вопросы} вопрос(ов) по {фул_с_вопросами} ФУЛ
• Уже учтены в Cloud, действий не нужно: {уже_учтены}        ← строка выводится, только если > 0

Файл: Распределение_ФУЛ_{дата}.xlsx

Главное, что нужно решить:                                    ← до 7 пунктов
— ФУЛ {номер} (заказ {заказ}): {что не так}. {что решить}.
— и ещё {n} — на листе «Требует внимания».

Агент ничего не записывал в Cloud и 1С: строки переносите после проверки. Основание по каждому ФУЛ — на листе «Журнал решений».
```

При ошибке входных данных:

```
ОШИБКА: не удалось найти: {чего нет}. Проверьте, что приложены выгрузка ФУЛ из 1С, реестр Cloud и список сотрудников из 1С, и что в них есть строка заголовков.
Приложенные файлы: {список}
```
