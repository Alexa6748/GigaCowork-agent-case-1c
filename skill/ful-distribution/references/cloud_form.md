# Форма строки реестра Cloud (12 колонок)

Колонки выводятся **в том порядке, в котором они стоят в приложенном реестре Cloud**, с его названиями заголовков. Лишние колонки реестра в форму не попадают. Если какой-то из 12 колонок в реестре нет, она добавляется в конец с типовым названием и вопросом в «Требует внимания».

| № | Колонка (типовое название) | Чем заполняется для нового ФУЛ |
|---|---|---|
| 1 | Заказ | Номер из комментария ФУЛ («Номер: S0001234 от …») |
| 2 | Поставщик | Написание из Cloud; для нового поставщика — из 1С (Контрагент) |
| 3 | Бренд | Бизнес-единица из 1С |
| 4 | Логист | «Фамилия И.О.» выбранного логиста; пусто, если не назначен |
| 5 | статус | «в работе» |
| 6 | дата подтверждения | пусто (заполняет логист) |
| 7 | cut-off | Cut-off date из 1С, как есть |
| 8 | Дата получения УЛ | Дата ФУЛ из 1С (без времени) |
| 9 | Страна отправления | Страна из 1С, как есть |
| 10 | Способ доставки | air / sea / truck / railway / direct truck (приведено к нижнему регистру) |
| 11 | Документы получены | пусто |
| 12 | Комментарий | пусто; «Повторная отправка ФУЛа, ДД.ММ.ГГГГ», если в пачке был дубль заказа |

Если исходного значения нет, в ячейке пишется «не определено» (ячейка подсвечена жёлтым). Пустой «Логист» подсвечен красным.
