# Распределение ФУЛ между логистами

## Когда применять

- Пользователь приложил файлы Excel (.xlsx, .xls) или CSV — **даже если текст сообщения пустой**. Пустое сообщение с файлами и есть запрос на распределение.
- Пользователь просит распределить ФУЛ / заказы, подготовить строки для Cloud, найти повторные отправки или пропуски.

Если файлов нет — коротко попроси приложить три выгрузки: ФУЛ из 1С, реестр Cloud, сотрудники из 1С.

## Как запустить

Решения о статусе ФУЛ, группе и логисте принимает **только скрипт**. Ничего не считай и не распределяй сам.

1. Возьми пути ко **всем** приложенным файлам. Какой файл чем является, определять не нужно: скрипт сам находит выгрузки по заголовкам колонок, в любом порядке, на любом листе.
2. Выполни (путь к навыку подставь свой):

```bash
python3 <папка навыка>/scripts/distribute.py --inputs <файл1> <файл2> <файл3> --out <папка для результата>
```

   - `--inputs` — файлы или папка с файлами, через пробел; пути с пробелами бери в кавычки.
   - `--out` — папка, откуда пользователь сможет скачать результат (например, папка outputs рабочего пространства).
   - Нужны только Python 3 и `openpyxl` (для `.xls` — `xlrd`). Сеть не используется.
3. Скрипт создаёт в `--out` файл `Распределение_ФУЛ_<дата>.xlsx` (+ `.json` с теми же данными) и печатает в stdout готовый ответ для чата.

## Как ответить пользователю

- **Код возврата 0.** Перешли пользователю текст из stdout **без изменений** (это и есть шаблон ответа: сколько новых строк, повторных отправок, пропусков и вопросов) и приложи Excel-файл. Не добавляй своих выводов о логистах, не пересчитывай цифры, не дописывай значения, которых нет в выводе.
- **Код возврата 2 (строка начинается с «ОШИБКА:»).** Перескажи ошибку своими словами в 1–2 предложениях и попроси приложить недостающий файл. Ничего не распределяй вручную.
- **Другая ошибка (исключение Python).** Сообщи, что файл не удалось обработать, и приведи последнюю строку ошибки. Не пытайся получить результат другим способом.

## Если пользователь задаёт вопросы по результату

Отвечай только по файлу результата: лист «Журнал решений» (колонка «Основание» — почему выбран логист, «Кандидаты группы» — загрузка и история каждого), «Требует внимания», «Загрузка логистов». Данные также есть в `.json` рядом с файлом. Если ответа в результате нет — так и скажи. Если пользователь просит распределить иначе, объясни, что агент применяет согласованные правила, а изменить решение может сотрудник при переносе строк в Cloud.

## Чего не делать

- Не придумывать группу, логиста, номер заказа, страну, способ доставки и другие значения. Где данных нет, в результате стоит «не определено» — так и оставляй.
- Не передавать заказ в другую группу, если в своей группе нет доступных логистов.
- Не записывать ничего в Cloud, 1С, почту и другие системы — результат только файл.

## Состав навыка

- `scripts/distribute.py` — правила распределения, чтение выгрузок, запись результата.
- `references/config.json` — справочник: синонимы заголовков, способы доставки, страны «Китай», ключевые слова должностей и состояний, шаблон комментария. Правила меняются здесь, без правки кода.
- `references/rules.md` — правила распределения человеческим языком (для ответов на вопросы «почему»).
- `references/cloud_form.md` — форма строки реестра Cloud и откуда берётся каждое поле.
- `references/answer_template.md` — шаблон ответа в чат.
