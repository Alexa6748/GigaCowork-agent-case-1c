# Агент распределения ФУЛ между логистами (GigaCowork)

Тестовое задание «Разработка AI-агентов на GigaCowork». Агент принимает три выгрузки (ФУЛ из 1С, реестр заказов Cloud, сотрудники из 1С) и **без текста запроса** выдаёт Excel-файл:

- новые строки Cloud по форме реестра (12 колонок, в порядке реестра);
- повторные отправки и дубли внутри пачки;
- возможные пропуски;
- «Требует внимания»;
- журнал решений с обоснованием по каждому ФУЛ;
- загрузку логистов.

Решения о статусе ФУЛ, группе и логисте принимает детерминированный Python-скрипт навыка. Модель только запускает его и пересылает готовый ответ.

## Сдача

| Файл | Что внутри |
|---|---|
| [`dist/GigaCowork_агент_ФУЛ.zip`](dist/) | Навык `ful-distribution.zip`, `system_prompt.txt`, `ИНСТРУКЦИЯ.md` — для загрузки в GigaCowork |
| [`dist/Тестовые_данные_ФУЛ.zip`](dist/) | Три набора данных, эталоны, генератор, скрипт метрик, результаты прогонов |
| [`dist/Отчёт_агент_распределения_ФУЛ.pdf`](dist/) | Вопросы заказчику, алгоритм, допущения, тестовые данные, метрики, лог прогона |

## Структура

```
skill/ful-distribution/       навык GigaCowork
  SKILL.md                    YAML (name, description) + инструкция для модели
  scripts/distribute.py       правила распределения (stdlib + openpyxl, xlrd для .xls)
  references/                 config.json (справочник правил), rules.md, cloud_form.md, answer_template.md
agent/
  system_prompt.txt           системный промпт агента
  ИНСТРУКЦИЯ.md               установка и запуск
testdata/
  generator.py                генератор синтетических данных и эталона
  evaluate.py                 контрольные прогоны и метрики приёмки
  datasets/                   A_основной, B_формат, C_крайние: входные файлы + Эталон.xlsx + эталон.json
  results/script/             3 прогона скрипта на каждом наборе, metrics.md
  results/agent/              3 прогона агента с пустым сообщением (набор A)
report/                       исходники PDF-отчёта (HTML, схемы Mermaid, скриншоты)
dist/                         архивы и PDF для сдачи
```

## Быстрый запуск

```bash
pip install openpyxl xlrd
python3 skill/ful-distribution/scripts/distribute.py \
  --inputs testdata/datasets/A_основной/входные_файлы --out ./result
```

Файлы можно передавать в любом порядке, списком или папкой. Тип файла и колонки определяются по заголовкам. В stdout выводится готовый ответ для чата.

Метрики:

```bash
cd testdata
python3 generator.py --out datasets          # пересоздать данные (для .xls нужен xlwt)
python3 evaluate.py --skill ../skill/ful-distribution --datasets datasets --runs 3 --out results/script
```

## Результаты

| Метрика | Порог | Результат (3 набора × 3 прогона + 3 прогона агента) |
|---|---|---|
| ФУЛ, совпавшие с эталоном по всем полям | ≥ 95 % | 100 % |
| Форма Cloud: 12 колонок в порядке реестра, без старых ФУЛ и дублей | 100 % прогонов | 100 % |
| Выдуманные значения на ловушках | 0 | 0 |
| Воспроизводимость | одинаково | одинаково, хеш агента = хешу прямого запуска |
| Назначения с обоснованием | 100 % | 100 % |
| Время ответа | ≤ 60 с | скрипт ≈ 0,25 с; агент 15–17 с |

Агент собран в формате GigaCowork и проверен в агентном рабочем пространстве с файлами и запуском Python. В прогонах агента использовалась лёгкая языковая модель тестового стенда: ей передавались только системный промпт, папка навыка и три файла, сообщение было пустым. Целевая модель для заказчика — GigaChat. Данные синтетические, все компании и сотрудники вымышленные.
